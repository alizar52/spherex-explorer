# Для команды

## Что это
Сайт под задание Planet X / SPHEREx. Вводишь RA/Dec или выбираешь объект, и сайт показывает все снимки SPHEREx этого места по датам, как видео. То, что сдвинулось или изменило яркость, видно глазом, и это же отмечает алгоритм.

Для обычного человека есть:
- стартовый экран с тремя историями (Barnard's Star, WISE 0855, Epsilon Indi B) и туром по интерфейсу; каждая история подсвечивает часть экрана и объясняет её;
- подсказки при наведении на любую кнопку, как в Blender: заголовок, объяснение, горячая клавиша.

## Как это отвечает на 5 критериев
- **Influence (Impact).** В снимках SPHEREx больше миллиарда объектов, учёным не проверить всё самим. Сайт даёт любому человеку смотреть снимки и замечать движение, как волонтёры Backyard Worlds находят коричневые карлики.
- **Creativity.** Снимки показаны как негатив стеклянной пластинки, по ним идёт лента миниатюр-кадров. Истории ведут человека от «что это» до настоящего измерения. Детектор сравнивает звёзды с соседями, а не просто вычитает кадры.
- **Validity.** Barnard's Star найдена автоматически: 11.9″/год против 10.4″ по каталогу. Epsilon Indi B: 4.5″/год против 4.7″. Где данных не хватает (WISE 0855, пересвеченные звёзды), сайт так и пишет, а не показывает красивые неправильные числа.
- **Relevance.** Всё из задания: ввод RA/Dec, видео из снимков, 5 тестовых объектов, выбор поля, сложение и вычитание кадров, детекторы D1–D6, спектр, Gaia/WISE, координаты в ссылке, флаги качества, Astropy и Aladin.
- **Presentation.** Стартовый экран сразу говорит проблему, решение и ценность. Для слайдов есть схема `docs/architecture.svg`.

## Масштабируемость
Схема `docs/architecture.svg`: в центре данные (FITS из архива IRSA), вокруг пайплайн, потом JSON, и только снаружи сайт. Каждый слой меняется отдельно:
- новые данные SPHEREx: перезапустить пайплайн, сайт не трогать;
- ML-модель Рината дописывает свои находки в `detections` того же JSON, и сайт их сразу показывает;
- другой сайт или приложение может читать те же JSON-файлы.

## Как обновить данные (когда придут новые FITS)
```
pip install -r backend/requirements.txt
python pipeline/build_static.py --metadata ПАПКА/metadata.csv --fits-root ПАПКА --challenge-dir ПАПКА/nasa_demo --out site/data --fresh
```
Файлы ищутся по имени, структура папок не важна. Потом залить папку `site` на GitHub.

## Что нужно от новых FITS
- вырезки 70–90 px, как в nasa_demo, а не 12×12;
- 6–8+ кадров на объект, разнесённых на месяцы;
- не только D6: в нём яркие звёзды пересвечены, нужны D1–D3;
- центр по координатам на дату съёмки (с собственным движением);
- полные файлы со слоями FLAGS, VARIANCE, ZODI.

## Поиск по любым координатам
На GitHub Pages его нет, потому что нужен сервер. На защите запустить на ноутбуке:
```
uvicorn backend.app:app --port 8000
```
и открыть http://localhost:8000. Тогда появятся выбор размера поля, отметки Gaia/WISE на снимке и поиск по любой точке неба.
